# Telegram-Manager-Setuper
Fast &amp; Easily setup your Telegram Accounts

Software will automatically disable privacy settings, add Username and Avatar on your Telegram Accounts.

1. Run `requirements.bat`
2. Add usernames in `names.txt`
3. In main directory, create 2 folders `avatars` and `sessions`:
Add images in avatars, create 2 folders in sessions `invalid` and `new`.
4. Add .session files in `sessions/new`
5. Run `main.py`.
